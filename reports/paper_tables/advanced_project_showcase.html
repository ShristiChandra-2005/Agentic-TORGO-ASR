How The Project Was Done

Experimental Design

The project first established Whisper baselines, then tested GAN-based enhancement, then added agentic post-ASR correction stages one by one. Each stage was evaluated on validation using WER, CER, and sentence accuracy before freezing.

Final Test Rule

The test set was used only after validation tuning and final pipeline freeze. This prevents test-set leakage and makes the reported final test result suitable for research reporting.
