Research Workflow

1. TORGODysarthric and control speech with transcripts.
2. PreprocessingResampling, transcript cleaning, validation.
3. WhisperTiny/Small baseline and fine-tuned ASR.
4. GAN StudyCWGAN-GP and ACGAN augmentation comparison.
5. AgentsCharacter, Word, Sentence baseline, Verification.
6. Final TestFrozen pipeline evaluated once on held-out test set.

Final Agentic Pipeline

Selected pipeline: Best Whisper baseline → Character Agent v4 → Word Agent v3 → Final Verification Agent. Sentence Agent v2 was evaluated but not frozen because manual inspection showed missed repeated hallucination patterns and sentence accuracy dropped slightly.

What Each Agent Does

Character Agent

Conservative character-level correction for malformed ASR tokens. It uses train-only vocabulary, edit similarity, phonetic-light similarity, and confidence thresholds.

Word Agent

Corrects valid-but-wrong confusion words and removes repeated ASR artifacts such as repeated tokens and image-prompt hallucination patterns.

Sentence Agent Baseline

Local seq2seq grammar-correction baseline with detector and verifier. Evaluated but not frozen in the final system.

Verification Agent

Final deterministic safety layer that removes obvious artifacts and repeated hallucinations without broad semantic rewriting.
